# נתניה פייטר · Netanya Fighter

משחק מכות בין חברים: דניאל, אדיר, לירון, גאולה, אלי, ליאב, גל, מיכאל, נויה ויובל. אפשר לשחק מול המחשב (שלוש רמות קושי) או אונליין בין טלפונים, בלי חשבון.

חדש: **בריחה מהשוטרת**, מיני משחק ריצה לשחקן יחיד. רצים דרך נתניה (חוף, שוק, טיילת, כיכר, אצטדיון ומספרה), קופצים וגולשים מתחת למכשולים, אוספים מטבעות וכוחות, ויובל וסנואו רודפות אחריכם. השיא נשמר במכשיר.

**לשחק:** https://adir430.github.io/netanya-fighter/

- אפשר להוסיף למסך הבית. אייפון: Safari, כפתור השיתוף, "הוסף למסך הבית". אנדרואיד: Chrome, "התקן אפליקציה".
- אונליין: רק שם תצוגה, ואז או "חפש יריב" (המשחק מוצא מישהו שמחפש באותו רגע) או לובי עם קוד. הטלפונים מדברים דרך שרתי MQTT ציבוריים וחינמיים.
